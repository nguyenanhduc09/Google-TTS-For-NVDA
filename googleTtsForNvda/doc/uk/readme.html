Google TTS для NVDA

Автори: Нгуєн Ань Дик (Nguyen Anh Duc), Дао Дик Чунг (Dao Duc Trung) та Фам Хунг Вионг (Pham Hung Vuong)

Застереження щодо незалежності: Google TTS для NVDA — це незалежний проєкт із відкритим вихідним кодом у галузі доступності. Він не пов’язаний із компанією Google LLC, не спонсорується та не схвалений нею. Google є торговельною маркою компанії Google LLC.

Протягом тривалого часу користувачі програм екранного доступу мріяли про можливість використовувати знайомі голоси технології синтезу мовлення Google у NVDA для Windows, подібно до того, як це реалізовано в програмах екранного доступу для Android.

Додаток Google TTS для NVDA було створено саме для здійснення цього бажання. Завдяки використанню технології синтезу мовлення Google через WebAssembly (WASM), яка працює в підтримуваному фоновому середовищі браузера Chromium (наприклад, Google Chrome, Microsoft Edge або Brave), цей додаток надає знайомі природні голоси Google для зручної щоденної роботи за комп’ютером.

Після завантаження потрібних голосових пакетів додаток працює повністю автономно на вашому комп’ютері, забезпечуючи швидкий відгук мовлення й не потребуючи постійного підключення до інтернету.

Основні можливості

  • Повністю автономна робота: Синтез мовлення виконується локально після завантаження необхідних голосових пакетів.
  • Розмаїття мов і голосів: Надає безліч голосових пакетів Google TTS для підтримуваних мов.
  • Швидкий відгук і низька затримка: Використовує сегментацію тексту та аудіобуферизацію для підвищення швидкодії NVDA.
  • Менеджер голосів Google TTS: Перегляд, завантаження, видалення та перевірка голосових пакетів у зручному доступному діалоговому вікні.
  • Вибір середовища виконання браузера Chromium: Можливість вибрати Google Chrome, Microsoft Edge або Brave як підтримуване фонове середовище браузера.
  • Автоматичні мовні профілі: Додаткова можливість використовувати профілі для кожної мови окремо, завдяки чому різні мови можуть мати власний голос і параметри мовлення.
  • Вбудоване оновлення додатка: Перевірка оновлень додатка безпосередньо з налаштувань NVDA з можливістю автоматичної перевірки один раз під час запуску.

Системні вимоги

  • NVDA: Версія 2024.1 або новіша. Додаток підтримує NVDA від 2024 до 2027 як для 32-розрядних (x86), так і для 64-розрядних (x64) збірок NVDA.
  • Браузер Chromium: Встановлений на вашому комп’ютері Google Chrome, Microsoft Edge або Brave. Якщо як середовище виконання використовується Microsoft Edge, також має бути доступне середовище виконання Microsoft Edge WebView2 Runtime.
  • Інтерактивний сеанс користувача Windows: Не покладайтеся на цей додаток у середовищах, де середовище виконання браузера Chromium не може запуститися, наприклад, на екрані входу у Windows, на захищених робочих столах, у Windows PE, середовищах відновлення або інших мінімальних сеансах Windows.

Короткий посібник із початку роботи

  1. Відкрийте діалогове вікно NVDA Вибір синтезатора (NVDA+Ctrl+S) і виберіть Google TTS для NVDA.
  2. Якщо жодного голосового пакета ще не встановлено, NVDA покаже повідомлення про відсутність встановлених голосів Google TTS для NVDA. Натисніть кнопку Гаразд, щоб відкрити Менеджер голосів Google TTS і завантажити голосовий пакет. Натисніть Скасувати, щоб наразі залишити поточний синтезатор.
  3. У Менеджері голосів Google TTS завантажте щонайменше один голосовий пакет на вкладці Завантажити.
  4. Після завантаження відкрийте Налаштування мовлення (NVDA+Ctrl+V), щоб вибрати бажану мову та варіант голосу.

Керування голосовими пакетами

Ви можете відкрити Менеджер голосів Google TTS у будь-який час, щоб додати або видалити голосові пакети:

  • Натисніть комбінацію клавіш NVDA+Ctrl+Shift+G або
  • Перейдіть у Меню NVDA → Інструменти → Менеджер голосів Google TTS...

Менеджер голосів Google TTS має дві вкладки:

  • Встановлено: Показує голосові пакети, які вже збережені на вашому комп’ютері. Стовпець Статус повідомляє, чи є пакет придатним до використання (Можна використовувати), чи він не підтримується вбудованим рушієм, чи відсутній обов’язковий для нього пакет, чи потрібен він іншому встановленому пакету, або ж залежить від іншого пакета.
  • Завантажити: Показує пакети, доступні для завантаження. Стовпець Статус пояснює, чи доступний пакет для завантаження, чи потребує він іншого пакета, чи вже встановлено потрібний для нього пакет, або ж чи потрібен він іншим доступним для завантаження пакетам.

На кожній вкладці елементи керування розташовані в такому порядку: Відфільтрувати за мовою, Позначити всі голосові пакети, список пакетів, а потім Видалити позначені голосові пакети або Завантажити позначені голосові пакети. Діалогове вікно також містить рядок Статус і кнопки Оновити, Відкрити папку голосових пакетів та Закрити.

Щоб додати голоси, перейдіть на вкладку Завантажити, позначте потрібні пакети прапорцями й натисніть Завантажити позначені голосові пакети. Щоб видалити голоси, відкрийте вкладку Встановлено, позначте пакети, які вам більше не потрібні, і натисніть Видалити позначені голосові пакети.

Деякі голосові пакети залежать від іншого пакета. Під час завантаження залежного пакета Менеджер голосів може автоматично завантажити й обов’язковий пакет. Під час видалення пакета, від якого залежать інші встановлені пакети, Менеджер голосів включає ці залежні пакети до списку видалення, щоб у системі не залишалися непридатні для використання голоси.

Менеджер голосів захищає від випадкового видалення останнього придатного голосового пакета. Якщо «Google TTS для NVDA» не є поточним синтезатором, у вікні попередження типово вибрано кнопку Ні. Якщо ж Google TTS для NVDA є поточним активним синтезатором, Менеджер голосів запропонує спочатку перемкнутися на інший синтезатор і залишить останній придатний пакет встановленим, якщо ви не перемкнете синтезатор.

Ви можете скористатися спадним списком Відфільтрувати за мовою на будь-якій вкладці, щоб показувати голосові пакети лише для потрібної мови (наприклад, англійської чи в’єтнамської) і знаходити голоси значно швидше. Крім того, ви можете натиснути кнопку Відкрити папку голосових пакетів, якщо бажаєте перевірити, де саме голосові пакети зберігаються на вашому комп’ютері.

Завантаження та видалення голосів відбуваються у фоновому режимі, тому ви можете продовжувати користуватися NVDA без перерв. Озвучення поступу повідомляється лише на ключових етапах і після завершення операції, щоб не повторювати кожну дрібну зміну відсотків.

Конфігурація

Налаштування мовлення

Діалогове вікно налаштувань мовлення NVDA (NVDA+Ctrl+V) містить параметр Паузи для Google TTS для NVDA незалежно від того, увімкнено чи вимкнено автоматичні мовні профілі. Коли автоматичні мовні профілі вимкнено, у цьому діалозі також доступні такі параметри:

  • Голос: Вибір встановленої мови Google TTS.
  • Варіант: Вибір назви голосу в межах цієї мови, зокрема голосів Chrome OS та Google Natural (якщо їх встановлено).
  • Швидкість: Регулювання швидкості читання.
  • Додаткове прискорення: Увімкнення подвоєння швидкості мовлення для читання на високій швидкості.
  • Висота: Регулювання висоти тону голосу.
  • Гучність: Регулювання гучності мовлення.

Паузи: Вибір того, чи залишатимуться паузи без змін, скорочуватимуться лише в кінці тексту або ж скорочуватимуться по всьому тексту для швидшого читання. Це налаштування застосовується до всього мовлення Google TTS.

Налаштування додатка

У розділі Меню NVDA → Параметри → Налаштування... → Google TTS для NVDA ви можете налаштувати:

  • Середовище виконання браузера Chromium: Вибір Google Chrome, Microsoft Edge або Brave як фонового середовища браузера Chromium для роботи додатка. На панелі налаштувань відображається стан доступності кожного браузера.
  • Стан середовища виконання браузера Chromium: Перегляд вибраного середовища виконання, доступності браузерів та активного резервного середовища, якщо воно використовується.
  • Підтримувати готовність середовища виконання Google TTS для браузера у фоновому режимі: Увімкніть, щоб Google TTS міг заздалегідь підготувати середовище браузера та поточний голосовий пакет під час використання іншого синтезатора, завдяки чому повернення до Google TTS відбуватиметься швидше. За замовчуванням цю функцію вимкнено. Після її ввімкнення та натискання кнопки «Гаразд» або «Застосувати» додаток може використовувати більше оперативної пам’яті та тримати відкритими файли середовища виконання до вимкнення параметра або виходу з NVDA.
  • Стан фонового середовища виконання браузера: Відображення того, чи вимкнено цей параметр, чи в ньому немає потреби (оскільки Google TTS уже є поточним синтезатором), або ж він очікує на запуск після натискання «Гаразд» чи «Застосувати».
  • Використовувати автоматичні мовні профілі: Увімкнення автоматичного вибору профілів та відкриття доступу до елементів керування профілями, описаних нижче.
    • Бажана мова профілю: Вибір мови з-поміж увімкнених профілів, яка використовуватиметься, якщо мову речення не вдалося визначити однозначно. Цей список може бути порожнім, доки не буде увімкнено хоча б один мовний профіль.
    • Автоматичний мовний профіль: Вибір встановленого мовного профілю для редагування.
    • Використовувати цей мовний профіль: Увімкнення вибраного мовного профілю.
    • Варіант, Швидкість, Додаткове прискорення, Висота, Гучність, Змінювати висоту голосу для великих літер у відсотках, Промовляти «велика літера» перед великими літерами, Звуковий сигнал для великих літер, Використовувати функцію посимвольного читання, якщо підтримується: Налаштування параметрів мовлення для вибраного увімкненого профілю.
    • Стан автоматичних мовних профілів: Перегляд того, чи профілі вимкнено, недоступні, чи не вибрано жодного профілю, або ж вони активні.
  • Оновлення: Містить наведені нижче елементи керування оновленнями додатка.
    • Автоматично перевіряти наявність оновлень для додатка під час запуску NVDA: Дозволяє Google TTS для NVDA виконувати одну перевірку після наступного запуску NVDA. За замовчуванням вимкнено.
    • Стан оновлення додатка: Відображає встановлену версію додатка, стан автоматичної перевірки під час запуску (увімкнено/вимкнено), а також чи виконується перевірка в цей момент.
    • Перевірити наявність оновлень...: Ручна перевірка наявності найновішого стабільного випуску додатка.

Категорію налаштувань «Google TTS для NVDA» можна також відкривати за допомогою власного жесту вводу. За замовчуванням комбінацію клавіш не призначено; ви можете призначити її в розділі Меню NVDA → Параметри → Жести вводу в категорії Google TTS для NVDA.

Оновлення додатка

Відкрийте Меню NVDA → Параметри → Налаштування... → Google TTS для NVDA і натисніть Перевірити наявність оновлень..., щоб перевірити наявність найновішої стабільної версії. Під час ручної перевірки з’явиться діалогове вікно з кнопкою «Гаразд», якщо додаток уже оновлено до актуальної версії, якщо відсутній зв’язок з інтернетом або якщо відповідь сервера оновлень не вдалося розпізнати.

Якщо доступна новіша версія, «Google TTS для NVDA» відкриє діалогове вікно Інформація про оновлення із зазначенням розміру завантаження, мінімальної та останньої протестованої версії NVDA, а також журналу змін. Виберіть Так, щоб завантажити пакет .nvda-addon безпосередньо в NVDA. Під час завантаження у вікні Завантаження оновлення Google TTS для NVDA відображатимуться Стан завантаження, індикатор поступу (якщо розмір відомий) і кнопка Скасувати. Додаток автоматично перевіряє завантажений файл за розміром і контрольною сумою SHA256 із маніфесту оновлення, після чого відкриває стандартний інсталятор додатків NVDA.

Автоматична перевірка під час запуску за замовчуванням вимкнена. Якщо ви її ввімкнете, «Google TTS для NVDA» здійснюватиме одну фонову перевірку після наступного запуску NVDA і не відволікатиме повідомленнями, якщо новішої версії немає. Ручна перевірка залишається доступною незалежно від стану автоматичної перевірки. Якщо фонова перевірка під час запуску вже виконується, коли відкрито категорію налаштувань, кнопка ручної перевірки буде тимчасово неактивною до завершення фонового процесу. Зміна стану прапорця Автоматично перевіряти наявність оновлень для додатка під час запуску NVDA набуває чинності для наступних запусків NVDA і не перериває перевірку, яка вже виконується.

Модуль оновлення також уміє розпізнавати невеликі виправлення (hotfix-збірки) в межах тієї самої публічної версії. Це дозволяє розробникам оперативно публікувати виправлення сумісності або надійності без зміни номера версії, а NVDA запропонує оновлення, щойно нові метадані випуску з’являться на сервері.

Автоматичні мовні профілі

Коли опцію Використовувати автоматичні мовні профілі увімкнено, розпізнані речення озвучуються за допомогою окремих мовних профілів додатка замість звичайних параметрів у діалозі «Налаштування мовлення» NVDA. Якщо ввімкнено лише один мовний профіль, саме він використовуватиметься для кожного речення. Звичайні параметри мови та варіанту Google TTS знову стають доступними, коли автоматичні мовні профілі вимкнено.

Автоматичні мовні профілі використовують вбудовані бібліотеки розпізнавання мови CLD2 як для 32-розрядних (x86), так і для 64-розрядних (x64) збірок NVDA. Результати CLD2 враховуються лише тоді, коли визначення є достатньо надійним для однієї з увімкнених мов. Якщо текст занадто короткий або неоднозначний, додаток використовує обережні локальні ознаки мови (якщо вони доступні), а в разі їх відсутності перемикається на бажану мову серед увімкнених профілів.

  1. Відкрийте Меню NVDA → Параметри → Налаштування... → Google TTS для NVDA.
  2. Увімкніть прапорець Використовувати автоматичні мовні профілі.
  3. Перейдіть до списку Бажана мова профілю. У ньому з’являються лише ввімкнені мови, тому він може бути порожнім, доки ви не ввімкнете хоча б один профіль.
  4. Виберіть Автоматичний мовний профіль.
  5. Позначте прапорець Використовувати цей мовний профіль для кожної мови, яку ви хочете задіяти в автоперемиканні. Мовні профілі залишаються неактивними, доки не встановлено цей прапорець.
  6. Для кожної ввімкненої мови налаштуйте Варіант, Швидкість, Додаткове прискорення, Висота, Гучність, Змінювати висоту голосу для великих літер у відсотках, Промовляти «велика літера» перед великими літерами, Звуковий сигнал для великих літер та Використовувати функцію посимвольного читання, якщо підтримується.
  7. Поверніться до поля Бажана мова профілю і виберіть мову з увімкнених, яка використовуватиметься за замовчуванням, якщо речення не вдалося розпізнати чітко.

Швидкість, висота та гучність налаштовуються повзунками, як і в стандартних «Налаштуваннях мовлення» NVDA. Висота для великих літер регулюється числовим полем введення зі стрілками для точного налаштування.

Загальносистемні налаштування NVDA, такі як рівень символів і пунктуації, автоматичне перемикання діалектів, повідомлення про зміну мови, нормалізація юнікоду, дані Консорціуму Юнікоду (включно з емодзі), додаткові словники символів, відкладений опис символів під час переміщення курсора та вибір режиму озвучення, як і раніше, залишаються в «Налаштуваннях мовлення» NVDA.

Google TTS ігнорує власні команди NVDA щодо автоматичного перемикання мови та діалектів для цього синтезатора, тому ці глобальні параметри не змушують Google TTS змінювати голоси. Використовуйте автоматичні мовні профілі Google TTS, якщо бажаєте мати автоматичний вибір голосу/профілю в цьому додатку. Якщо ввімкнено опцію NVDA Повідомляти про зміну мови під час читання, назви озвучуваних мов відповідатимуть розпізнаванню мовних профілів Google TTS, поки профілі активні. Коли профілі вимкнено, NVDA може продовжувати використовувати мовні мітки від програм для сповіщення про мову та обробки символів (зокрема словників пунктуації й символів), проте сам Google TTS не перемикатиме голоси за цими командами.

Автоматичні мовні профілі встановлюють мовний контекст до того, як NVDA починає обробку тексту, тому вимова символів і мовленнєві словники NVDA працюють у звичному режимі для контексту вибраної мови.

Коли автоматичні мовні профілі вимкнено, голосові словники NVDA працюють у звичайному режимі для поточного вибраного варіанта Google TTS. Коли автопрофілі ввімкнено, додаток тимчасово застосовує голосовий словник для вибраного варіанта кожного увімкненого мовного профілю під час обробки відповідного сегмента. Загальний і тимчасовий словники NVDA функціонують у стандартному режимі NVDA.

Поки автоматичні мовні профілі ввімкнено, діалогове вікно налаштувань мовлення NVDA не містить стандартних елементів вибору голосу, варіанта, швидкості, додаткового прискорення, висоти та гучності для цього синтезатора. Натомість там відображається сповіщення у доступному для фокусування полі, яке спрямовує вас до категорії налаштувань «Google TTS для NVDA». Параметр Паузи залишається доступним у налаштуваннях мовлення й застосовується до всього мовлення Google TTS. Стандартні команди кільця параметрів синтезатора (NVDA+Ctrl+Стрілки на настільних клавіатурах або NVDA+Shift+Ctrl+Стрілки на ноутбуках) озвучують це сповіщення замість зміни параметрів голосу чи мовлення Google TTS у цьому режимі. Google TTS також застосовує параметри великих літер і посимвольного читання кожного увімкненого профілю, поки автоматичні мовні профілі діють; стандартні значення з «Налаштувань мовлення» знову повертаються після вимкнення автоматичних профілів. Рядки стану в категорії налаштувань «Google TTS для NVDA» також доступні для переходу клавішею Tab, тому програми екранного доступу можуть безперешкодно їх озвучувати.

Усунення проблеми відсутності звуку в середовищі виконання Edge

Якщо ви вибрали Microsoft Edge як середовище браузера Chromium, «Google TTS для NVDA» додатково перевіряє наявність Microsoft Edge WebView2 Runtime. Edge може бути встановлений у системі, але компонент WebView2 може бути відсутнім або пошкодженим — у такому разі додаток не зможе використовувати Edge для озвучення. Google Chrome та Brave не залежать від WebView2.

WebView2 — це середовище виконання Microsoft Edge, яке використовується класичними програмами Windows для відображення вебвмісту. Воно пов’язане з Microsoft Edge, проте наявність звичайного браузера Edge не завжди означає, що середовище WebView2 Runtime встановлене й функціонує належним чином для програмних сценаріїв. Корпорація Microsoft рекомендує використовувати Evergreen WebView2 Runtime для програм, оскільки воно є спільним для системи, автоматично оновлюється, а невеликий установник Evergreen Bootstrapper автоматично завантажує відповідне середовище виконання для архітектури вашого пристрою.

Якщо виникає потреба у WebView2, Google TTS для NVDA пропонує кнопки для завантаження онлайн-інсталятора Microsoft Evergreen Bootstrapper, відкриття сторінки Microsoft WebView2 для вибору офлайн-інсталяторів чи пакетів фіксованої версії, або ж збереження вибору на потім. Доки WebView2 не стане доступним, NVDA продовжуватиме використовувати попередній синтезатор.

Якщо Windows не вдається відкрити сторінку завантаження, додаток відобразить адресу посилання у підписаному полі, доступному лише для читання, та надасть кнопку Копіювати посилання, щоб ви могли вставити адресу в браузер вручну.

Для комп’ютера з підключенням до інтернету завантажте Microsoft Edge WebView2 Evergreen Bootstrapper за цим посиланням: Завантажити Microsoft Edge WebView2 Runtime.

Запустіть установник, перезапустіть NVDA, а потім знову виберіть Google TTS для NVDA. Для отримання офлайн-інсталяторів або пакета фіксованої версії WebView2 Runtime відкрийте офіційну сторінку Microsoft: Microsoft Edge WebView2.

  • Доступність налаштувань: Додано команду в «Жести вводу» (без призначеної комбінації за замовчуванням) для безпосереднього відкриття налаштувань «Google TTS для NVDA», покращено поля стану для надійного озвучення міток і повних повідомлень скринрідерами, а кільце параметрів синтезатора налаштовано на озвучення сповіщення про дію автоматичних мовних профілів замість зміни параметрів голосу, коли цю функцію ввімкнено. Це зберігає параметри голосу сумісними зі стандартними «Налаштуваннями мовлення» NVDA.
  • Вибір і надійність голосів: Зроблено зрозумілішим вибір мови та варіанта, безпечнішим попереднє прогрівання голосу, покращено роботу з пакетами в Менеджері голосів, пришвидшено скасування мовлення, захищено імпорт голосових пакетів та виправлено регіональні назви мов, такі як English (Nigeria).
