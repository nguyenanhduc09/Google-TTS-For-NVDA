Google TTS Para NVDA

Autores: Nguyen Anh Duc, Dao Duc Trung y Pham Hung Vuong

Aviso de independencia: Google TTS Para NVDA es un proyecto de accesibilidad independiente y de código abierto. No está afiliado a Google LLC ni cuenta con su patrocinio o respaldo. Google es una marca comercial de Google LLC.

Durante mucho tiempo, los usuarios de lectores de pantalla han deseado utilizar en NVDA para Windows las voces conocidas de la tecnología de texto a voz de Google, con una experiencia parecida a la de los lectores de pantalla de Android.

Google TTS Para NVDA se creó para cumplir ese deseo. Este complemento utiliza la tecnología de texto a voz de Google mediante WebAssembly (WASM) y la ejecuta en segundo plano a través de un navegador Chromium compatible como Google Chrome, Microsoft Edge o Brave. De este modo, incorpora voces naturales y conocidas de Google para mejorar el uso diario del ordenador.

Una vez descargados los paquetes de voz que quieras utilizar, el complemento funciona completamente sin conexión en el ordenador y ofrece una respuesta rápida sin necesitar una conexión continua a Internet.

Características principales

  • Funcionamiento totalmente sin conexión: la voz se procesa localmente después de descargar los paquetes necesarios.
  • Variedad de idiomas y voces: ofrece varios paquetes de voz de Google TTS para los idiomas compatibles.
  • Respuesta rápida y baja latencia: utiliza segmentación de texto y búfer de audio para mejorar la respuesta de NVDA.
  • Administrador de voces de Google TTS: permite explorar, descargar, eliminar y consultar paquetes de voz desde un diálogo accesible.
  • Selección del entorno de ejecución del navegador Chromium: permite elegir Google Chrome, Microsoft Edge o Brave como entorno de ejecución de un navegador Chromium compatible en segundo plano.
  • Perfiles de idioma automáticos: permite utilizar perfiles por idioma para que cada idioma tenga su propia voz y sus propios valores de lectura.
  • Actualizaciones integradas del complemento: permite buscar actualizaciones desde Opciones de NVDA y, opcionalmente, efectuar una búsqueda automática cada vez que se inicia NVDA.

Requisitos del sistema

  • NVDA: versión 2024.1 o posterior. El complemento admite NVDA de 2024 a 2027, tanto en compilaciones de NVDA de 32 bits (x86) como de 64 bits (x64).
  • Entorno de ejecución del navegador Chromium: debes tener instalado en el ordenador al menos uno de estos navegadores: Google Chrome, Microsoft Edge o Brave. Si utilizas Microsoft Edge como entorno de ejecución, también debe estar disponible el entorno de ejecución de Microsoft Edge WebView2.
  • Sesión interactiva de usuario de Windows: no dependas de este complemento en entornos donde no pueda iniciarse el entorno de ejecución del navegador Chromium, como la pantalla de inicio de sesión de Windows, escritorios seguros, Windows PE, entornos de recuperación u otras sesiones mínimas de Windows.

Guía de inicio rápido

  1. Abre el diálogo Seleccionar Sintetizador de NVDA pulsando NVDA+Ctrl+S y elige Google TTS Para NVDA.
  2. Si no hay paquetes de voz instalados, NVDA mostrará un mensaje indicando que no hay voces de Google TTS Para NVDA instaladas. Pulsa Aceptar para abrir el Administrador de voces de Google TTS y descargar un paquete de voz. Pulsa Cancelar para seguir utilizando el sintetizador actual por ahora.
  3. En el Administrador de voces de Google TTS, descarga al menos un paquete de voz desde la pestaña Descargar.
  4. Después de descargarlo, abre Opciones de Voz (NVDA+Ctrl+V) para seleccionar el idioma y la variante que prefieras.

Gestión de voces

Puedes abrir el Administrador de voces de Google TTS en cualquier momento para añadir o eliminar paquetes de voz:

  • Pulsa el atajo NVDA+Ctrl+Mayús+G, o
  • Ve a Menú NVDA → Herramientas → Administrador de voces de Google TTS...

El Administrador de voces de Google TTS tiene dos pestañas:

  • Instalados: muestra los paquetes de voz que ya están guardados en el ordenador. La columna Estado indica si cada paquete es Utilizable, no es compatible con el motor incluido, necesita un paquete que falta, lo necesita otro paquete instalado o depende de otro paquete.
  • Descargar: muestra los paquetes que se pueden descargar. La columna Estado indica si un paquete está disponible para descargar, necesita otro paquete, ya tiene instalado el paquete necesario o lo necesitan otros paquetes descargables.

En cada pestaña, los controles aparecen en este orden: Filtrar por idioma, Marcar todos los paquetes de voz, la lista de paquetes y, después, Eliminar los paquetes de voz marcados o Descargar los paquetes de voz marcados. El diálogo también tiene una línea de Estado y los botones Actualizar, Abrir la carpeta de paquetes de voz y Cerrar.

Para añadir voces, utiliza la pestaña Descargar, marca los paquetes que quieras y pulsa Descargar los paquetes de voz marcados. Para eliminar voces, utiliza la pestaña Instalados, marca los paquetes que ya no quieras y pulsa Eliminar los paquetes de voz marcados.

Algunos paquetes de voz dependen de otro paquete. Al descargar un paquete dependiente, el Administrador de voces también puede descargar el paquete necesario. Al eliminar un paquete del que dependen otros paquetes instalados, el Administrador de voces incluye esos paquetes dependientes para no dejar voces inutilizables.

El Administrador de voces impide que elimines por accidente el último paquete de voz utilizable. Si Google TTS Para NVDA no es el sintetizador actual, la opción predeterminada del aviso es No. Si Google TTS Para NVDA es el sintetizador actual, el Administrador de voces te pide que cambies primero a otro sintetizador y conserva instalado el último paquete utilizable si no realizas el cambio.

Puedes utilizar el cuadro combinado Filtrar por idioma de cualquiera de las dos pestañas para mostrar solo los paquetes del idioma que quieras, por ejemplo inglés o vietnamita, y encontrar las voces más rápidamente. También puedes pulsar Abrir la carpeta de paquetes de voz para consultar dónde se guardan los paquetes en el ordenador.

Las descargas y eliminaciones se realizan en segundo plano para que puedas seguir utilizando NVDA sin interrupciones. Los anuncios de progreso se limitan a hitos generales y resultados finales para no repetir cada pequeño cambio porcentual.

Configuración

Opciones de Voz

El diálogo Opciones de Voz de NVDA (NVDA+Ctrl+V) ofrece Pausas para Google TTS Para NVDA tanto si los perfiles de idioma automáticos están activados como si están desactivados. Cuando están desactivados, el diálogo también ofrece:

  • Voz: elige un idioma de Google TTS para el que haya un paquete de voz instalado.
  • Variante: elige el nombre de voz dentro de ese idioma, incluidas las voces de Chrome OS y Google Natural cuando estén instaladas.
  • Velocidad: ajusta la velocidad de lectura.
  • Aumento de la Velocidad: actívalo para duplicar la velocidad de la voz cuando quieras leer a gran velocidad.
  • Tono: ajusta el tono de la voz.
  • Volumen: ajusta el volumen de la voz.

Pausas: elige si las pausas se conservan sin cambios, se acortan solo al final del texto o se acortan durante toda la lectura para aumentar la velocidad. Esta opción se aplica a toda la lectura de Google TTS.

Opciones del complemento

En Menú NVDA → Preferencias → Opciones → Google TTS Para NVDA puedes configurar:

  • Entorno de ejecución del navegador Chromium: elige Google Chrome, Microsoft Edge o Brave como entorno de ejecución del navegador Chromium en segundo plano para el complemento. El panel de opciones muestra la disponibilidad de los navegadores.
  • Estado del entorno de ejecución del navegador Chromium: consulta el entorno seleccionado, la disponibilidad del navegador y el entorno alternativo activo cuando se utilice uno.
  • Mantener preparado en segundo plano el entorno de ejecución del navegador de Google TTS: activa esta opción para que Google TTS prepare el entorno de ejecución del navegador y el paquete de voz actual mientras está activo otro sintetizador, lo que puede acelerar el cambio de vuelta a Google TTS. Esta opción está desactivada de forma predeterminada. Después de activarla y pulsar Aceptar o Aplicar, el complemento puede utilizar más memoria y mantener abiertos archivos del entorno hasta que desactives la opción o salgas de NVDA.
  • Estado del entorno de ejecución del navegador en segundo plano: consulta si esta opción está desactivada, si no es necesaria porque Google TTS ya es el sintetizador actual o si está esperando para iniciarse después de pulsar Aceptar o Aplicar.
  • Utilizar perfiles de idioma automáticos: activa la selección automática de perfiles y muestra los controles descritos más adelante.
    • Idioma del perfil preferido: elige un idioma cuyo perfil esté activado para utilizarlo cuando el idioma de una frase no esté claro. La lista puede estar vacía hasta que se active al menos un perfil de idioma.
    • Perfil de idioma automático: elige el perfil de idioma instalado que quieras editar.
    • Utilizar este perfil de idioma: activa el perfil de idioma seleccionado.
    • Variante, Velocidad, Aumento de la Velocidad, Tono, Volumen, Cambio de Porcentaje de Tono para Mayúsculas, Decir “Mayus” antes de mayúsculas, Pitar para Mayúsculas y Utilizar funcionalidad de deletreo si está soportada: configura los valores de voz del perfil activado seleccionado.
    • Estado de los perfiles de idioma automáticos: consulta si los perfiles están desactivados, no están disponibles, no tienen un perfil seleccionado o están activos.
  • Actualizaciones: contiene los controles de actualización descritos a continuación.
    • Buscar automáticamente actualizaciones del complemento al iniciar NVDA: permite que Google TTS Para NVDA realice una búsqueda la próxima vez que se inicie NVDA. Esta opción está desactivada de forma predeterminada.
    • Estado de actualización del complemento: consulta la versión instalada, si las búsquedas automáticas al iniciar están activadas o desactivadas y si hay una búsqueda en curso.
    • Buscar actualizaciones...: busca manualmente la versión estable más reciente del complemento.

La categoría de opciones de Google TTS Para NVDA también puede abrirse mediante un gesto de entrada personalizado. No tiene ningún atajo asignado de forma predeterminada; asígnalo desde Menú NVDA → Preferencias → Gestos de Entrada, en la categoría Google TTS Para NVDA.

Actualizaciones del complemento

Abre Menú NVDA → Preferencias → Opciones → Google TTS Para NVDA y pulsa Buscar actualizaciones... para consultar la versión estable más reciente. Las búsquedas manuales muestran un diálogo con el botón Aceptar cuando el complemento ya está actualizado, cuando no se puede acceder a Internet o cuando no se puede interpretar la respuesta del servidor.

Cuando hay disponible una versión más reciente, Google TTS Para NVDA muestra un diálogo de Información de la actualización con el tamaño de descarga, la versión mínima de NVDA, la última versión de NVDA probada y el registro de cambios. Elige Sí para descargar el paquete .nvda-addon desde NVDA. Durante la descarga, el diálogo Descargando la actualización de Google TTS Para NVDA muestra el Estado de la descarga, una barra de progreso cuando se conoce el tamaño y el botón Cancelar. El complemento verifica el archivo descargado comparando su tamaño y suma de comprobación SHA256 con el manifiesto de actualización y, después, abre el instalador de complementos normal de NVDA.

Las búsquedas automáticas al iniciar están desactivadas de forma predeterminada. Si las activas, Google TTS Para NVDA realizará una búsqueda la próxima vez que se inicie NVDA y no anunciará nada a menos que haya una versión más reciente. La búsqueda manual continúa disponible tanto si las búsquedas automáticas están activadas como si no. Si ya hay una búsqueda en segundo plano mientras está abierta la categoría de opciones, el botón de búsqueda manual permanece desactivado hasta que termine. Cambiar la casilla Buscar automáticamente actualizaciones del complemento al iniciar NVDA afecta a los próximos inicios de NVDA y no interrumpe una búsqueda que ya esté en curso.

El actualizador también reconoce pequeñas compilaciones de corrección dentro de una misma versión pública. Esto permite publicar correcciones de compatibilidad o fiabilidad sin cambiar el número de versión mostrado, y NVDA puede seguir ofreciendo una compilación más reciente si los metadatos de la versión indican que está disponible.

Perfiles de idioma automáticos

Cuando se activa Utilizar perfiles de idioma automáticos, las frases detectadas utilizan los perfiles por idioma del complemento en lugar de las Opciones de Voz normales de NVDA. Si solo se activa un perfil, se utiliza para todas las frases. Las opciones normales de idioma y variante de Google TTS vuelven a estar disponibles cuando se desactivan los perfiles de idioma automáticos.

Los perfiles de idioma automáticos utilizan bibliotecas de detección CLD2 incluidas para compilaciones de NVDA de 32 bits (x86) y 64 bits (x64). Los resultados de CLD2 solo se aceptan cuando son suficientemente fiables para uno de los idiomas activados. Si el texto es demasiado corto o ambiguo, el complemento aplica criterios prudentes basados en indicios lingüísticos locales cuando están disponibles y, después, recurre al idioma preferido activado.

  1. Abre Menú NVDA → Preferencias → Opciones → Google TTS Para NVDA.
  2. Activa Utilizar perfiles de idioma automáticos.
  3. Ve a Idioma del perfil preferido. Solo aparecen en esta lista los idiomas activados, por lo que puede estar vacía hasta que actives un perfil.
  4. Selecciona un Perfil de idioma automático.
  5. Marca la casilla Utilizar este perfil de idioma para cada idioma que quieras utilizar con los perfiles de idioma automáticos. Los perfiles están desactivados hasta que se marca esta casilla.
  6. Para cada idioma activado, configura Variante, Velocidad, Aumento de la Velocidad, Tono, Volumen, Cambio de Porcentaje de Tono para Mayúsculas, Decir “Mayus” antes de mayúsculas, Pitar para Mayúsculas y Utilizar funcionalidad de deletreo si está soportada.
  7. Vuelve a Idioma del perfil preferido y elige el idioma activado que se utilizará cuando una frase no esté clara.

Velocidad, tono y volumen utilizan controles deslizantes como los de Opciones de Voz de NVDA. El tono de las mayúsculas utiliza un control de edición numérica con flechas para que puedas ajustarlo con precisión.

Las opciones generales de NVDA, como Nivel de Puntuación y símbolos, Cambio Automático de Dialecto, Indicar cambios de idioma durante la lectura, Normalización Unicode, Incluir datos Unicode Consortium (incluyendo emoji) al procesar caracteres y símbolos, los diccionarios de pronunciación de símbolos adicionales, Descripciones retrasadas para caracteres en movimientos del cursor y los modos de voz, permanecen en Opciones de Voz de NVDA.

Google TTS ignora las órdenes de cambio automático de idioma y dialecto de NVDA para este sintetizador, por lo que esas opciones generales no obligan a Google TTS a cambiar de voz. Utiliza los perfiles de idioma automáticos de Google TTS cuando quieras seleccionar automáticamente una voz o un perfil dentro de este complemento. Si está activada la opción de NVDA Indicar cambios de idioma durante la lectura, los nombres de idiomas anunciados siguen la detección de los perfiles de Google TTS mientras estos estén activados. Cuando están desactivados, NVDA todavía puede utilizar los cambios de idioma proporcionados por la aplicación para anunciar el idioma y procesar caracteres y símbolos, incluidos los diccionarios de puntuación y símbolos, pero Google TTS no cambiará de voz mediante esas órdenes.

Los perfiles de idioma automáticos establecen el contexto de idioma antes de que NVDA procese el texto, por lo que la pronunciación de símbolos y el procesamiento de los diccionarios de voz de NVDA siguen formando parte del flujo normal de voz para el contexto seleccionado.

Cuando los perfiles de idioma automáticos están desactivados, los diccionarios por voces de NVDA funcionan normalmente para la variante de Google TTS seleccionada. Cuando están activados, el complemento utiliza temporalmente el diccionario por voces correspondiente a la variante seleccionada de cada perfil activado mientras NVDA procesa ese segmento. Los diccionarios predeterminado y temporal de NVDA mantienen su comportamiento normal.

Mientras los perfiles de idioma automáticos estén activados, el diálogo Opciones de Voz de NVDA no ofrecerá los controles normales de Voz, Variante, Velocidad, Aumento de la Velocidad, Tono y Volumen para este sintetizador. En su lugar, mostrará un aviso que puede recibir el foco y te dirigirá a la categoría de opciones de Google TTS Para NVDA. Pausas seguirá disponible en Opciones de Voz y se aplicará a toda la lectura de Google TTS. Las órdenes normales del Anillo de Opciones de Sintetizador, como NVDA+Ctrl+flechas en teclados de escritorio o NVDA+Mayús+Ctrl+flechas en teclados portátiles, anunciarán este aviso en vez de cambiar la voz o sus valores en este modo. Google TTS también utilizará las opciones de mayúsculas y deletreo de cada perfil activado mientras estén activos los perfiles automáticos; los valores normales de Opciones de Voz volverán a estar disponibles al desactivarlos. También puedes llegar con Tab a los mensajes de estado de la categoría Google TTS Para NVDA para que el lector de pantalla los anuncie.

Solución de problemas de silencio con el entorno de ejecución de Edge

Si eliges Microsoft Edge como entorno de ejecución del navegador Chromium, Google TTS Para NVDA también comprueba si está disponible el entorno de ejecución de Microsoft Edge WebView2. Edge puede estar instalado aunque WebView2 falte o esté dañado; en ese caso, el complemento no puede utilizar Edge para generar voz. Google Chrome y Brave no dependen de WebView2.

WebView2 es el entorno de ejecución de Microsoft Edge que utilizan las aplicaciones nativas de Windows para alojar contenido web. Está relacionado con Microsoft Edge, pero disponer del navegador Edge normal no siempre significa que el entorno de ejecución de WebView2 esté instalado y funcione correctamente para las aplicaciones. Microsoft recomienda el entorno de ejecución Evergreen de WebView2 porque se comparte entre aplicaciones y se actualiza automáticamente. Su pequeño instalador Evergreen Bootstrapper descarga el entorno adecuado para la arquitectura del dispositivo.

Cuando se necesita WebView2, Google TTS Para NVDA ofrece botones para descargar el instalador en línea Evergreen Bootstrapper de Microsoft, abrir la página de WebView2 de Microsoft para obtener instaladores sin conexión o paquetes de versión fija, o dejar el cambio para más adelante. NVDA continúa utilizando el sintetizador anterior hasta que WebView2 esté disponible.

Si Windows no puede abrir la página de descarga, el complemento muestra la dirección en un campo etiquetado de solo lectura e incluye un botón Copiar enlace para que puedas pegarla manualmente en un navegador.

En un ordenador conectado a Internet, descarga aquí el instalador Evergreen Bootstrapper de Microsoft Edge WebView2: Descargar el entorno de ejecución de Microsoft Edge WebView2.

Ejecuta el instalador, reinicia NVDA y vuelve a seleccionar Google TTS Para NVDA. Para obtener instaladores sin conexión o un paquete de versión fija del entorno de ejecución de WebView2, abre la página de Microsoft: Microsoft Edge WebView2.

Notas

  • No necesitas mantener abierta una ventana de Google Chrome, Microsoft Edge o Brave mientras utilizas NVDA. El complemento se conecta automáticamente y procesa la voz en segundo plano.
  • La primera vez que NVDA hable después de iniciarse, las voces pueden tardar unos instantes en inicializarse.

Registro de cambios

Versión 1.1 (20/10/2026)

  • Actualización de seguridad: se reforzó la protección de la comunicación interna con el entorno de ejecución del navegador Chromium, rechazando conexiones procedentes de orígenes web externos.
  • Compatibilidad con NVDA: se actualizó la compatibilidad para NVDA 2027.1.
  • Motor actualizado: se actualizó el motor WASM TTS incluido a la versión 2027xxxx.1.

Versión 1.0 (12/10/2026)

  • Lectura más rápida y fluida:
    • Para textos medianos y largos, el complemento utiliza ahora una primera sección más corta para empezar a hablar antes y procesa después el texto restante en secciones más grandes.
    • El complemento puede reutilizar el audio ya generado que se conserva temporalmente en la RAM. Al leer por primera vez un texto largo, también almacena en el búfer una pequeña cantidad de audio antes de reproducirlo para reducir las interrupciones.
  • Mejor tratamiento del texto multilingüe:
    • Las divisiones de frases y expresiones utilizan ahora un conjunto más amplio de datos oficiales de puntuación y sistemas de escritura de Unicode 17.0 y CLDR 48.2. Esto mejora el tratamiento de la puntuación localizada, las abreviaturas, las direcciones web, los emojis, el chino, el japonés, el coreano, el tailandés y otros textos que no utilizan espacios con regularidad.
    • La función Utilizar perfiles de idioma automáticos puede aprovechar esta cobertura más amplia de sistemas de escritura para seleccionar con mayor precisión el perfil más probable cuando el texto es corto o el idioma no está claro.
    • La opción Pausas y las transiciones entre secciones son más uniformes, tanto si el audio se reutiliza desde la RAM como si se acaba de generar.
  • Mayor volumen y más estabilidad:
    • El complemento utiliza ahora una amplificación fija para aumentar el volumen predeterminado y evitar subidas y bajadas anormales durante la lectura. La opción Volumen sigue siendo proporcional y se mantiene la protección frente a picos demasiado altos.
    • La distorsión de algunas voces masculinas ya está presente en la salida del motor WASM TTS original, por lo que el complemento no puede corregirla mediante el procesamiento posterior. Estos cambios mejoran el volumen y su estabilidad; no pretenden reducir esa distorsión.
  • Mayor fiabilidad:
    • Si el entorno de ejecución del navegador Chromium o el motor WASM TTS falla antes de producir audio, Google TTS descarta el entorno defectuoso y vuelve a intentarlo una vez con uno nuevo. Si el audio ya ha comenzado, el complemento no lo vuelve a intentar para evitar repetir una parte de la lectura.
    • La opción Mantener preparado en segundo plano el entorno de ejecución del navegador de Google TTS ya no conserva un entorno ocupado, desconectado o en mal estado.
    • El complemento ahora solo carga los componentes que incluye, lo que reduce los conflictos con componentes de nombre parecido cargados por otros complementos de NVDA.
    • El complemento se recupera con mayor fiabilidad cuando el dispositivo de salida de audio de NVDA cambia o entra en estado de error en las versiones compatibles de NVDA.
  • Componentes y traducciones actualizados:
    • Se actualizó el motor WASM TTS incluido a la versión 20260917.1.
    • Se añadieron las traducciones de la interfaz y la documentación al español y al portugués de Brasil.
    • Se reescribieron las traducciones al chino simplificado de la interfaz y la documentación para que el texto resulte más natural y utilice la terminología oficial de NVDA.

Versión 0.6 (30/07/2026)

  • Cambio de sintetizador más rápido: se añadió una opción para preparar con antelación el entorno de ejecución y el paquete de voz actual de Google TTS al cambiar desde otro sintetizador. Está desactivada de forma predeterminada y, al activarla, puede utilizar más memoria mientras NVDA esté en ejecución.
  • Preparación en segundo plano: cuando se activa esta opción, Google TTS actualiza su preparación en segundo plano después de cambiar el navegador Chromium seleccionado o instalar y eliminar paquetes de voz.
  • Mayor fiabilidad al cambiar: se mejoró la fiabilidad al dejar de utilizar Google TTS, especialmente mientras la lectura o la preparación del paquete de voz todavía se están deteniendo.

Versión 0.5.5 (23/07/2026)

  • Perfiles de idioma automáticos: se mejoró la correspondencia de perfiles entre CLD2 y los alias de códigos de idioma de Google TTS, incluidos filipino/tagalo, javanés, códigos antiguos de hebreo, variantes de noruego, árabe y correspondencias de chino simplificado, tradicional y cantonés.
  • DLL de CLD2 para Windows: las DLL incluidas se recompilaron con MSVC en lugar de MinGW-w64 para que el complemento empaquetado dejara de provocar el falso positivo de antivirus anterior en las pruebas de VirusTotal.

Versión 0.5 (19/07/2026)

  • Actualizaciones del complemento: se añadió la búsqueda integrada de actualizaciones desde la categoría de opciones de Google TTS Para NVDA, con búsquedas opcionales al iniciar, información localizada, descarga del paquete desde NVDA, transferencia al instalador de complementos normal y compatibilidad con pequeñas compilaciones de corrección dentro de una misma versión pública.
  • Cambio automático entre entornos Chromium: se mejoró el cambio entre Chrome, Edge y Brave para que Google TTS Para NVDA pueda probar otro navegador compatible cuando el seleccionado no se inicia o no está preparado. Edge puede omitirse cuando falta WebView2 y hay otro entorno compatible utilizable. Google TTS Para NVDA también espera y vuelve a intentarlo mientras el navegador termina de iniciarse, lo que reduce los escasos fallos silenciosos de inicio o conexión.
  • Compatibilidad con NVDA: se mejoró la compatibilidad con versiones anteriores y posteriores de NVDA en la síntesis de voz, el deletreo, los diccionarios por voces, las opciones, el cambio de sintetizador, el complemento global y el controlador del sintetizador. Google TTS también impide que las órdenes de cambio de idioma de NVDA o de las aplicaciones cambien las voces de Google, pero las conserva para anunciar el idioma y procesar caracteres y símbolos cuando los perfiles automáticos están desactivados.
  • Localización en chino simplificado, chino tradicional y ruso: se añadieron traducciones de la interfaz y la documentación de usuario. Las dos variantes de chino también incluyen metadatos localizados del complemento.
  • Fiabilidad de la voz: se corrigieron casos poco frecuentes en los que una lectura interrumpida podía reproducirse de forma incompleta, se restauró el control Tono para las voces SeaNet y se evitó un error poco frecuente de Opciones de Voz tras cambiar desde Google TTS. Se añadió la opción Pausas para acortarlas opcionalmente; actívala desde Opciones de Voz de NVDA (NVDA+Ctrl+V). Encontrarás más detalles en la sección Configuración.
  • Accesibilidad de los campos de estado: se facilitó que los campos de estado del entorno de ejecución, los perfiles automáticos, las actualizaciones, el aviso de Opciones de Voz y la dirección alternativa manual recibieran el foco y pudieran revisarse, sin anuncios repetidos con retraso.

Versión 0.4 (16/07/2026)

  • Perfiles de idioma automáticos: se añadieron perfiles de Google TTS por idioma inspirados en Auto TTS para Android. Se configuran desde la categoría Google TTS Para NVDA; cada idioma activado puede tener su propia Variante, Velocidad, Aumento de la Velocidad, Tono, Volumen, comportamiento de mayúsculas y deletreo, mientras las Opciones de Voz normales de NVDA siguen disponibles cuando la función está desactivada.
  • Compatibilidad con NVDA: se mejoró la compatibilidad con NVDA 2024.1 a 2026, incluido un cambio de sintetizador más seguro, un uso más seguro de los mecanismos de procesamiento de voz y un mejor comportamiento cuando otro complemento interviene en la selección de sintetizador de NVDA.
  • Lectura multilingüe de textos largos: se mejoró la división de frases y expresiones para textos con puntuación no ASCII o sistemas de escritura con pocos espacios entre palabras, incluida una cobertura de puntuación Unicode más amplia para muchos idiomas.
  • Compatibilidad con entornos Chromium: se añadió Brave, se mejoró el cambio automático entre Chrome, Edge y Brave desde la categoría Google TTS Para NVDA y se aclaró que el entorno de ejecución de Microsoft Edge WebView2 solo es necesario al utilizar Microsoft Edge.
  • Mejoras de documentación: se añadieron al README de GitHub instrucciones para establecer rutas personalizadas de Chrome, Edge y Brave mediante pasos accesibles en la interfaz de Windows, y se amplió la solución de problemas de Edge WebView2 tanto en la ayuda como en la documentación de GitHub.
  • Accesibilidad de las opciones: se añadió una orden sin gesto asignado para abrir directamente las opciones de Google TTS Para NVDA, se mejoraron los campos de estado para que los lectores de pantalla anuncien sus etiquetas y mensajes completos con mayor fiabilidad, y se hizo que el Anillo de Opciones de Sintetizador anuncie el aviso de perfiles automáticos en vez de cambiar valores cuando la función está activada. Esto mantiene los parámetros gestionados por perfiles compatibles con las Opciones de Voz normales de NVDA.
  • Selección y fiabilidad de voces: se aclaró la selección de Voz y Variante, se hizo más segura la preparación del paquete de voz, se mejoró la gestión de paquetes, la respuesta al interrumpir la lectura y la importación segura de paquetes, y se corrigieron nombres regionales como Inglés (Nigeria).
