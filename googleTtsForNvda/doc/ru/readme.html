Google TTS для NVDA

Авторы: Nguyen Anh Duc, Dao Duc Trung и Pham Hung Vuong

Уведомление о независимости: Google TTS For NVDA — это независимый открытый проект в области доступности. Он не связан с Google LLC, не спонсируется и не одобряется ею. Google является товарным знаком Google LLC.

Долгое время пользователи программ экранного доступа хотели использовать знакомые голоса технологии синтеза речи Google в NVDA для Windows — так же, как это происходит в программах экранного доступа на Android.

Google TTS For NVDA создан для воплощения этого желания. Используя технологию синтеза речи Google через WebAssembly (WASM), работающую в поддерживаемой фоновой среде браузера на основе Chromium, такой как Google Chrome, Microsoft Edge или Brave, это дополнение приносит знакомые, естественные голоса Google для повышения удобства ежедневной работы за компьютером.

После загрузки нужных голосовых пакетов дополнение работает полностью автономно на вашем компьютере, обеспечивая отзывчивую речь без необходимости постоянного подключения к интернету.

Ключевые возможности

  • Полностью автономная работа: речь обрабатывается локально после загрузки необходимых голосовых пакетов.
  • Разнообразие языков и голосов: предоставляет множество голосовых пакетов Google TTS для поддерживаемых языков.
  • Быстрый отклик и низкая задержка: использует сегментацию текста и буферизацию аудио для повышения отзывчивости NVDA.
  • Диспетчер голосов Google TTS: просматривайте, загружайте, удаляйте и проверяйте голосовые пакеты в доступном диалоговом окне.
  • Выбор среды браузера Chromium: выберите Google Chrome, Microsoft Edge или Brave в качестве поддерживаемой фоновой среды браузера.
  • Автоматические языковые профили: при желании используйте профили для каждого языка, чтобы разные языки могли иметь собственный голос и параметры речи.
  • Встроенные обновления дополнения: проверяйте обновления дополнения из настроек NVDA, с необязательной автоматической проверкой один раз при запуске.

Системные требования

  • NVDA: версия 2024.1 или новее. Дополнение поддерживает NVDA 2024–2027 как в 32-битных (x86), так и в 64-битных (x64) сборках NVDA.
  • Браузер Chromium: на компьютере должен быть установлен Google Chrome, Microsoft Edge или Brave. Если в качестве среды используется Microsoft Edge, также должна быть доступна среда выполнения Microsoft Edge WebView2 Runtime.
  • Интерактивный сеанс пользователя Windows: не полагайтесь на это дополнение там, где среда браузера Chromium не может запуститься, например на экране входа в Windows, в контекстах защищённого рабочего стола, в Windows PE, в средах восстановления или в других минимальных сеансах Windows.

Краткое руководство по началу работы

  1. Откройте диалоговое окно NVDA Выбор синтезатора, нажав NVDA+Ctrl+S, и выберите Google TTS For NVDA.
  2. Если голосовые пакеты не установлены, NVDA отобразит сообщение о том, что голоса Google TTS For NVDA не установлены. Нажмите OK, чтобы открыть Диспетчер голосов Google TTS и загрузить голосовой пакет. Нажмите Отмена, чтобы пока продолжить использовать текущий синтезатор.
  3. В Диспетчере голосов Google TTS загрузите хотя бы один голосовой пакет на вкладке Загрузка.
  4. После загрузки откройте Настройки речи (NVDA+Ctrl+V), чтобы выбрать предпочитаемый язык и вариант.

Управление голосами

Вы можете открыть Диспетчер голосов Google TTS в любое время, чтобы добавить или удалить голосовые пакеты:

  • Нажмите сочетание клавиш NVDA+Ctrl+Shift+G, или
  • Перейдите в Меню NVDA → Сервис → Диспетчер голосов Google TTS...

Диспетчер голосов Google TTS имеет две вкладки:

  • Установленные: показывает голосовые пакеты, уже сохранённые на вашем компьютере. Столбец Состояние сообщает, является ли каждый пакет Используемым, не поддерживается встроенным движком, отсутствует требуемый пакет, требуется другим установленным пакетом или зависит от другого пакета.
  • Загрузка: показывает пакеты, которые можно загрузить. Столбец Состояние поясняет, доступен ли пакет для загрузки, требует ли он другой пакет, уже установлен ли его требуемый пакет или он требуется другими загружаемыми пакетами.

На каждой вкладке элементы управления расположены в следующем порядке: Фильтр по языку, Отметить все голосовые пакеты, список пакетов, затем либо Удалить отмеченные голосовые пакеты, либо Загрузить отмеченные голосовые пакеты. В диалоговом окне также есть строка Состояние и кнопки Обновить, Открыть папку голосовых пакетов и Закрыть.

Чтобы добавить голоса, используйте вкладку Загрузка, отметьте нужные пакеты и нажмите Загрузить отмеченные голосовые пакеты. Чтобы удалить голоса, используйте вкладку Установленные, отметьте пакеты, которые больше не нужны, и нажмите Удалить отмеченные голосовые пакеты.

Некоторые голосовые пакеты зависят от другого пакета. При загрузке зависимого пакета Диспетчер голосов может также загрузить требуемый пакет. При удалении пакета, от которого зависят другие установленные пакеты, Диспетчер голосов включает эти зависимые пакеты, чтобы не оставлять неработоспособные голоса.

Диспетчер голосов защищает вас от случайного удаления последнего используемого голосового пакета. Если Google TTS For NVDA не является текущим синтезатором, предупреждение по умолчанию имеет значение Нет. Если Google TTS For NVDA является текущим синтезатором, Диспетчер голосов предложит сначала переключиться на другой синтезатор и сохранит последний используемый пакет установленным, если вы не переключитесь.

Вы можете использовать раскрывающийся список Фильтр по языку на любой вкладке, чтобы отображать только голосовые пакеты для нужного языка (например, английского или вьетнамского) и быстрее находить голоса. Кроме того, вы можете нажать Открыть папку голосовых пакетов, если хотите узнать, где на вашем компьютере хранятся голосовые пакеты.

Загрузка и удаление голосов выполняются в фоновом режиме, чтобы вы могли продолжать использовать NVDA без прерываний. Объявления о ходе выполнения ограничиваются основными этапами и окончательными результатами, чтобы они не повторялись при каждом небольшом изменении процента.

Настройка

Настройки речи

Диалоговое окно настроек речи NVDA (NVDA+Ctrl+V) предоставляет Паузы для Google TTS For NVDA независимо от того, включены автоматические языковые профили или нет. Когда автоматические языковые профили выключены, диалоговое окно также предоставляет:

  • Голос: выберите установленный язык Google TTS.
  • Вариант: выберите имя голоса в пределах этого языка, включая голоса Chrome OS и Google Natural, если они установлены.
  • Скорость: отрегулируйте скорость чтения.
  • Ускорение скорости: включите, чтобы удвоить скорость речи для высокоскоростного чтения.
  • Высота тона: отрегулируйте высоту тона голоса.
  • Громкость: отрегулируйте громкость речи.

Паузы: выберите, остаются ли паузы без изменений, сокращаются только в конце текста или сокращаются на протяжении всей речи для более быстрого чтения. Этот параметр применяется ко всей речи Google TTS.

Настройки дополнения

В разделе Меню NVDA → Параметры → Настройки → Google TTS For NVDA вы можете настроить:

  • Среда браузера Chromium: выберите Google Chrome, Microsoft Edge или Brave в качестве фоновой среды браузера Chromium для дополнения. Панель настроек отображает доступность браузеров.
  • Состояние среды браузера Chromium: просмотрите выбранную среду, доступность браузеров и активную резервную среду, когда она используется.
  • Поддерживать готовность среды браузера Google TTS в фоне: включите, чтобы Google TTS подготавливал среду браузера и текущий голосовой пакет, пока активен другой синтезатор, чтобы переключение обратно на Google TTS могло быть быстрее. Этот параметр по умолчанию выключен. После его включения и нажатия OK или Применить он может использовать больше памяти и держать файлы среды открытыми, пока вы его не выключите или не завершите NVDA.
  • Состояние фоновой среды браузера: просмотрите, выключен ли этот параметр, не нужен ли он, поскольку Google TTS уже является текущим синтезатором, или ожидает ли он запуска после нажатия OK или Применить.
  • Использовать автоматические языковые профили: включите автоматический выбор профиля и откройте элементы управления профилями, описанные ниже.
    • Предпочитаемый язык профиля: выберите включённый язык профиля, используемый, когда предложение неясно. Этот список может быть пустым, пока не включён хотя бы один языковой профиль.
    • Автоматический языковой профиль: выберите, какой установленный языковой профиль редактировать.
    • Использовать этот языковой профиль: включите выбранный языковой профиль.
    • Вариант, Скорость, Ускорение скорости, Высота тона, Громкость, Процент изменения высоты тона для заглавных, Произносить "заглавная" перед заглавными, Звуковой сигнал для заглавных, Использовать функцию произнесения по буквам, если поддерживается: настройте речевые значения для выбранного включённого профиля.
    • Состояние автоматических языковых профилей: просмотрите, выключены ли профили, недоступны ли они, отсутствует ли выбранный профиль или они активны.
  • Обновления: содержит элементы управления обновлением дополнения, описанные ниже.
    • Автоматически проверять обновления дополнения при запуске NVDA: позволить Google TTS For NVDA выполнить проверку один раз после следующего запуска NVDA. По умолчанию выключено.
    • Состояние обновления дополнения: просмотрите установленную версию дополнения, включены ли автоматические проверки при запуске или выключены, и выполняется ли проверка в данный момент.
    • Проверить обновления...: вручную проверить наличие последней стабильной версии дополнения.

Категорию настроек Google TTS For NVDA также можно открыть с помощью пользовательской команды ввода. По умолчанию ей не назначено сочетание клавиш; назначьте его в разделе Меню NVDA → Параметры → Жесты ввода в категории Google TTS For NVDA.

Обновления дополнения

Откройте Меню NVDA → Параметры → Настройки → Google TTS For NVDA и нажмите Проверить обновления..., чтобы проверить последнюю стабильную версию. При ручной проверке отображается диалоговое окно OK, если дополнение уже обновлено, если невозможно подключиться к интернету или если ответ об обновлении не удаётся понять.

Когда доступна более новая версия, Google TTS For NVDA показывает диалоговое окно Информация об обновлении с размером загрузки, минимальной версией NVDA, последней протестированной версией NVDA и списком изменений. Выберите Да, чтобы загрузить пакет .nvda-addon внутри NVDA. Во время загрузки диалоговое окно Загрузка обновления Google TTS For NVDA показывает Состояние загрузки, индикатор выполнения, когда размер известен, и Отмена. Дополнение проверяет загруженный файл на соответствие размеру и контрольной сумме SHA256 из манифеста обновления, а затем открывает стандартное средство установки дополнений NVDA.

Автоматические проверки при запуске по умолчанию выключены. Если вы их включите, Google TTS For NVDA выполняет проверку один раз после следующего запуска NVDA и молчит, если только не доступна более новая версия. Ручная проверка остаётся доступной независимо от того, включены автоматические проверки или нет. Если фоновая проверка при запуске уже выполняется, пока открыта категория настроек, кнопка ручной проверки отключена до завершения этой проверки. Изменение флажка Автоматически проверять обновления дополнения при запуске NVDA влияет на будущие запуски NVDA и не прерывает уже выполняющуюся проверку.

Средство обновления также может распознавать небольшие сборки с исправлениями в пределах одной и той же публичной версии. Это позволяет сопровождающим публиковать исправления совместимости или надёжности без изменения отображаемого номера версии, при этом NVDA всё равно может предложить более новую сборку, когда метаданные выпуска сообщают о её наличии.

Автоматические языковые профили

Когда Использовать автоматические языковые профили включено, обнаруженные предложения используют языковые профили дополнения вместо обычных настроек речи NVDA. Если включён только один языковой профиль, этот профиль используется для каждого предложения. Ваши обычные настройки языка и варианта Google TTS снова становятся доступными, когда автоматические языковые профили выключаются.

Автоматические языковые профили используют встроенные библиотеки определения языка CLD2 как для 32-битных (x86), так и для 64-битных (x64) сборок NVDA. Результаты CLD2 принимаются только тогда, когда они достаточно надёжны для одного из включённых языков. Если текст слишком короткий или неясный, дополнение использует консервативные локальные языковые признаки, где они доступны, а затем переходит к предпочитаемому включённому языку.

  1. Откройте Меню NVDA → Параметры → Настройки → Google TTS For NVDA.
  2. Включите Использовать автоматические языковые профили.
  3. Перейдите к Предпочитаемый язык профиля. В этом списке отображаются только включённые языки, поэтому он может быть пустым, пока вы не включите профиль.
  4. Выберите Автоматический языковой профиль.
  5. Установите флажок Использовать этот языковой профиль для каждого языка, который должны использовать автоматические языковые профили. Языковые профили выключены, пока этот флажок не установлен.
  6. Для каждого включённого языка задайте Вариант, Скорость, Ускорение скорости, Высоту тона, Громкость, Процент изменения высоты тона для заглавных, Произносить "заглавная" перед заглавными, Звуковой сигнал для заглавных и Использовать функцию произнесения по буквам, если поддерживается.
  7. Вернитесь к Предпочитаемый язык профиля и выберите включённый язык, используемый, когда предложение неясно.

Скорость, высота тона и громкость используют ползунки, как в настройках речи NVDA. Высота тона для заглавных букв использует числовое поле ввода/счётчик, чтобы вы могли настроить её точно.

Общесистемные настройки NVDA, такие как уровень пунктуации и символов, автоматическое переключение диалектов, сообщение об изменении языка, нормализация Unicode, данные консорциума Unicode, включая эмодзи, дополнительные словари символов, отложенные описания символов и выбор режима речи, остаются в настройках речи NVDA.

Google TTS игнорирует собственные команды NVDA автоматического переключения языка и диалекта для этого синтезатора, поэтому эти глобальные параметры не заставляют Google TTS менять голоса. Используйте автоматические языковые профили Google TTS, когда хотите автоматический выбор голоса/профиля в этом дополнении. Если параметр NVDA Сообщать об изменениях языка при чтении включён, сообщаемые названия языков следуют определению автоматических языковых профилей Google TTS, пока профили включены. Когда профили выключены, NVDA всё ещё может использовать изменения языка, предоставляемые приложением, для сообщения о языке и обработки символов/знаков, включая словари пунктуации и символов, но Google TTS не будет менять голоса по этим командам.

Автоматические языковые профили задают языковой контекст до того, как NVDA обработает текст, поэтому произношение символов и обработка словарей речи NVDA остаются в обычном речевом потоке для выбранного языкового контекста.

Когда автоматические языковые профили выключены, голосовые словари NVDA работают нормально для текущего выбранного варианта Google TTS. Когда автоматические языковые профили включены, дополнение временно использует голосовой словарь для выбранного варианта каждого включённого языкового профиля, пока NVDA обрабатывает этот сегмент. Словари NVDA по умолчанию и временные словари по-прежнему следуют обычному поведению NVDA.

Пока автоматические языковые профили включены, диалоговое окно настроек речи NVDA не будет предлагать обычные элементы управления голосом, вариантом, скоростью, ускорением скорости, высотой тона и громкостью для этого синтезатора. Оно покажет доступное для фокуса уведомление, направляющее вас в категорию настроек Google TTS For NVDA. Паузы остаются доступными в настройках речи и применяются ко всей речи Google TTS. Обычные команды кольца настроек синтезатора, такие как NVDA+Ctrl+Стрелки на настольных клавиатурах или NVDA+Shift+Ctrl+Стрелки на ноутбуках, объявляют это уведомление вместо изменения голоса или речевых значений Google TTS в этом режиме. Google TTS также использует параметры заглавных букв и произнесения по буквам каждого включённого профиля, пока автоматические языковые профили включены; обычные значения настроек речи снова становятся доступными, когда автоматические языковые профили выключаются. Сообщения о состоянии в категории настроек Google TTS For NVDA также доступны с помощью Tab, чтобы программы экранного доступа могли их объявлять.

Устранение неполадок с тишиной среды Edge

Если вы выбираете Microsoft Edge в качестве среды браузера Chromium, Google TTS For NVDA также проверяет, доступна ли среда выполнения Microsoft Edge WebView2 Runtime. Edge может быть установлен, а WebView2 — отсутствовать или быть повреждённым, и в этом случае дополнение не может использовать Edge для речи. Google Chrome и Brave не зависят от WebView2.

WebView2 — это среда выполнения Microsoft Edge, используемая собственными приложениями Windows для размещения веб-содержимого. Она связана с Microsoft Edge, но наличие обычного браузера Edge не всегда означает, что среда выполнения WebView2 установлена и работоспособна для сценариев приложений. Microsoft рекомендует для приложений Evergreen WebView2 Runtime, поскольку она является общей, автоматически обновляется, а небольшой Evergreen Bootstrapper загружает соответствующую среду выполнения для архитектуры устройства.

Когда требуется WebView2, Google TTS For NVDA предлагает кнопки для загрузки онлайн-загрузчика Microsoft Evergreen Bootstrapper, открытия страницы Microsoft WebView2 для офлайн-установщиков или пакетов фиксированных версий, либо откладывания изменения на потом. NVDA продолжает использовать предыдущий синтезатор, пока WebView2 не станет доступной.

Если Windows не может открыть страницу загрузки, дополнение показывает адрес загрузки в помеченном поле только для чтения и включает кнопку Копировать ссылку, чтобы вы могли вставить адрес в браузер вручную.

Для компьютера с доступом в интернет загрузите загрузчик Microsoft Edge WebView2 Evergreen Bootstrapper здесь: Загрузить Microsoft Edge WebView2 Runtime.

Запустите установщик, перезапустите NVDA, затем снова выберите Google TTS For NVDA. Для офлайн-установщиков или пакета среды выполнения WebView2 фиксированной версии откройте страницу Microsoft WebView2: Microsoft Edge WebView2.

Примечания

  • Вам не нужно держать открытым окно браузера Google Chrome, Microsoft Edge или Brave во время использования NVDA. Дополнение автоматически подключается и обрабатывает речь в фоновом режиме.
  • Когда NVDA впервые говорит после запуска, голосам может потребоваться некоторое время для инициализации.
