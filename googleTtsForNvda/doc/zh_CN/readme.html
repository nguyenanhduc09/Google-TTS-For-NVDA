NVDA 谷歌TTS插件

作者：Nguyen Anh Duc、Dao Duc Trung 和 Pham Hung Vuong

独立性声明：NVDA 谷歌TTS插件是一个独立的开源无障碍项目。本项目不隶属于 Google LLC，也未获得 Google LLC 的赞助或认可。Google 是 Google LLC 的商标。

长期以来，屏幕阅读器用户一直希望能在 Windows 版 NVDA 中使用熟悉的 谷歌TTS技术所提供的语音，获得类似于 Android 屏幕阅读器的体验。

NVDA 谷歌TTS插件 正是为了实现这一愿望而开发的。本插件通过 WebAssembly（WASM）使用 谷歌TTS技术，并借助 Google Chrome、Microsoft Edge 或 Brave 等受支持的 Chromium 浏览器运行时在后台运行，为您的日常电脑使用带来熟悉而自然的 Google 语音。

下载所需的语音包后，本插件便可完全在您的电脑上离线运行，无需持续连接互联网即可快速响应并朗读内容。

主要功能

  • 完全离线运行：下载所需的语音包后，语音将在本地处理。
  • 丰富的语言和语音：为受支持的语言提供多种适用于 谷歌TTS引擎的语音包。
  • 响应迅速、延迟较低：通过文本分段和音频缓冲提高 NVDA 的响应速度。
  • 谷歌TTS管理器：通过无障碍对话框浏览、下载、移除和查看语音包。
  • 选择 Chromium 浏览器运行时：可选择 Google Chrome、Microsoft Edge 或 Brave 作为受支持的后台浏览器运行时。
  • 自动语言配置文件：可选择为每种语言使用独立配置文件，让不同语言分别使用各自的语音和语音参数。
  • 内置插件更新：可在 NVDA 设置中检查插件更新，也可选择在每次启动时自动检查一次。

系统要求

  • NVDA：2024.1 或更高版本。本插件支持 NVDA 2024 至 2027，包括 32 位（x86）和 64 位（x64）版本。
  • Chromium 浏览器：电脑上需安装 Google Chrome、Microsoft Edge 或 Brave。如果使用 Microsoft Edge 作为浏览器运行时，还必须安装 Microsoft Edge WebView2 运行时。
  • 交互式 Windows 用户会话：请勿在 Chromium 浏览器运行时无法启动的环境中依赖本插件，例如 Windows 登录界面、安全桌面、Windows PE、恢复环境或其他精简 Windows 会话。

快速入门

  1. 打开 NVDA 的选择语音合成器对话框（按 NVDA+Ctrl+S），然后选择 NVDA 谷歌TTS插件。
  2. 如果尚未安装任何语音包，NVDA 会显示消息，提示尚未安装 NVDA 谷歌TTS插件的语音。按确定打开 谷歌TTS管理器并下载语音包；按取消暂时继续使用当前语音合成器。
  3. 在 谷歌TTS管理器的下载选项卡中，至少下载一个语音包。
  4. 下载完成后，打开语音设置（NVDA+Ctrl+V），选择您需要的语言和变声。

管理语音

您可以随时打开 谷歌TTS管理器来添加或移除语音包：

  • 按快捷键 NVDA+Ctrl+Shift+G；或
  • 依次打开 NVDA 菜单 → 工具 → 谷歌TTS管理器...

谷歌TTS管理器包含两个选项卡：

  • 已安装：显示已存储在电脑上的语音包。状态列会说明每个语音包是否可用、是否受随附引擎支持、是否缺少必需的语音包、是否被其他已安装的语音包所依赖，或是否依赖其他语音包。
  • 下载：显示可供下载的语音包。状态列会说明语音包是否可以下载、是否需要其他语音包、必需的语音包是否已经安装，或是否被其他可下载语音包所依赖。

每个选项卡上的控件依次为：按语言筛选、选中所有语音包、语音包列表，然后是移除选中的语音包或下载选中的语音包。对话框中还包含一行状态信息，以及刷新、打开语音包文件夹和关闭按钮。

要添加语音，请打开下载选项卡，选中所需的语音包，然后按下载选中的语音包。要移除语音，请打开已安装选项卡，选中不再需要的语音包，然后按移除选中的语音包。

某些语音包依赖其他语音包。下载有依赖项的语音包时，语音管理器也可以一并下载必需的语音包。如果要移除的语音包被其他已安装语音包所依赖，语音管理器会将依赖该语音包的其他包一并列入移除范围，以免留下无法使用的语音。

语音管理器会防止您误移除最后一个可用的语音包。如果 NVDA 谷歌TTS插件不是当前语音合成器，警告对话框默认选择否。如果 NVDA 谷歌TTS插件是当前语音合成器，语音管理器会要求您先切换到其他语音合成器；如果没有完成切换，则会保留最后一个可用的语音包。

您可以在任一选项卡中使用按语言筛选下拉框，只显示所需语言（例如英语或越南语）的语音包，以便更快找到语音。您还可以点击打开语音包文件夹，查看语音包在电脑上的存储位置。

语音包的下载和移除均在后台进行，因此您仍可继续使用 NVDA，不会受到干扰。进度提示只会在主要阶段和操作结束时播报，避免每次百分比发生细微变化时都重复提示。

配置

语音设置

无论是否启用自动语言配置文件，NVDA 的语音设置（NVDA+Ctrl+V）都会为 NVDA 谷歌TTS插件提供停顿选项。关闭自动语言配置文件时，其中还会提供以下选项：

  • 语音：选择已安装语音包所对应的 谷歌TTS语言。
  • 变声：选择该语言中的语音名称，包括已经安装的 Chrome OS 和 Google Natural 语音。
  • 速度：调整朗读速度。
  • 语速加倍：启用后将语音速度提高一倍，适合高速阅读。
  • 音调：调整语音的音调。
  • 音量：调整语音音量。

停顿：可选择保持停顿不变、仅缩短文本末尾的停顿，或缩短整个朗读过程中的停顿以加快阅读。此设置适用于 谷歌TTS的所有朗读内容。

插件设置

依次打开 NVDA 菜单 → 选项 → 设置 → NVDA 谷歌TTS插件，可以配置以下选项：

  • Chromium 浏览器运行时：选择 Google Chrome、Microsoft Edge 或 Brave 作为本插件的后台 Chromium 浏览器运行时。设置面板会显示各浏览器是否可用。
  • Chromium 浏览器运行时状态：查看所选运行时、浏览器可用性，以及发生回退时实际使用的运行时。
  • 让 谷歌TTS的浏览器运行时在后台保持就绪：启用后，即使当前正在使用其他语音合成器，谷歌TTS也可以提前准备浏览器运行时和当前语音包，从而加快切换回 谷歌TTS的速度。此选项默认关闭。启用后按“确定”或“应用”，本插件可能会占用更多内存，并会使运行时文件保持打开，直到您关闭此选项或退出 NVDA。
  • 后台浏览器运行时状态：查看此功能是处于关闭状态、因 谷歌TTS已是当前语音合成器而无需运行，还是正在等待您按“确定”或“应用”后启动。
  • 使用自动语言配置文件：启用自动选择配置文件，并显示下文所述的配置文件控件。
    • 首选配置文件语言：选择一个已启用的配置文件语言，在句子语言不明确时使用。在启用至少一个语言配置文件之前，此列表可能为空。
    • 自动语言配置文件：选择要编辑的已安装语言配置文件。
    • 使用此语言配置文件：启用所选的语言配置文件。
    • 变声、速度、语速加倍、音调、音量、大写时音高变化的百分比、遇到大写字母时先提示“大写”、遇到大写字母时发出提示音、在合成器支持的情况下激活拼读功能：为所选并已启用的配置文件设置语音参数。
    • 自动语言配置文件状态：查看自动语言配置文件是已关闭、不可用、尚未选择配置文件，还是正在使用。
  • 更新：包含下列插件更新控件。
    • NVDA 启动时自动检查插件更新：让 NVDA 谷歌TTS插件在下次启动 NVDA 时检查一次更新。此选项默认关闭。
    • 插件更新状态：查看已安装的插件版本、启动时自动检查是开启还是关闭，以及当前是否正在检查。
    • 检查更新...：手动检查最新的稳定版插件。

也可以通过自定义按键或手势打开 NVDA 谷歌TTS插件设置类别。此命令默认没有分配快捷键；请依次打开 NVDA 菜单 → 选项 → 按键与手势，在 NVDA 谷歌TTS插件 类别中进行分配。

插件更新

依次打开 NVDA 菜单 → 选项 → 设置 → NVDA 谷歌TTS插件，然后按检查更新...以检查最新稳定版。如果插件已是最新版本、无法连接互联网或无法识别服务器返回的更新信息，手动检查都会显示一个带“确定”按钮的对话框。

有新版本时，NVDA 谷歌TTS插件会显示更新信息对话框，其中包含下载大小、最低 NVDA 版本、最近测试的 NVDA 版本和更新日志。选择是可在 NVDA 中下载 .nvda-addon 安装包。下载期间，正在下载 NVDA 谷歌TTS插件更新对话框会显示下载状态、可在大小已知时显示的进度条，以及取消按钮。本插件会根据更新清单中的文件大小和 SHA256 校验值验证下载的文件，然后打开 NVDA 的标准插件安装程序。

启动时自动检查更新默认关闭。启用后，NVDA 谷歌TTS插件会在下次启动 NVDA 时检查一次，除非发现新版本，否则不会发出提示。无论自动检查是否开启，您都可以手动检查。如果打开设置类别时后台启动检查仍在进行，手动检查按钮将暂时禁用，直到检查完成。更改NVDA 启动时自动检查插件更新复选框只会影响以后启动 NVDA 时的行为，不会中断已经开始的检查。

更新程序还可以识别同一公开版本号下的小型修补版本。这样，维护者无需更改显示的版本号即可发布兼容性或可靠性修复；如果发布元数据表明已有较新的内部版本，NVDA 仍可提供该更新。

自动语言配置文件

启用使用自动语言配置文件后，检测到的句子会使用本插件针对各语言设置的配置文件，而不是 NVDA 的常规语音设置。如果只启用了一个语言配置文件，则每个句子都会使用该配置文件。关闭自动语言配置文件后，谷歌TTS的常规语言和变声设置会重新可用。

自动语言配置文件在 32 位（x86）和 64 位（x64）NVDA 中分别使用随附的 CLD2 检测器库。只有当 CLD2 的检测结果足够可靠，并且对应某种已启用的语言时，才会采用该结果。如果文本太短或语言不明确，本插件会尽量采用较为保守的本地语言特征进行判断；仍无法确定时，则回退到已启用的首选语言。

  1. 依次打开 NVDA 菜单 → 选项 → 设置 → NVDA 谷歌TTS插件。
  2. 启用使用自动语言配置文件。
  3. 移动到首选配置文件语言。此列表只显示已启用的语言，因此在启用配置文件前可能为空。
  4. 选择一个自动语言配置文件。
  5. 为希望自动使用的每种语言选中使用此语言配置文件复选框。未选中此复选框时，该语言配置文件处于关闭状态。
  6. 为每种已启用的语言设置变声、速度、语速加倍、音调、音量、大写时音高变化的百分比、遇到大写字母时先提示“大写”、遇到大写字母时发出提示音和在合成器支持的情况下激活拼读功能。
  7. 返回首选配置文件语言，选择在句子语言不明确时使用的已启用语言。

速度、音调和音量使用与 NVDA 语音设置相似的滑块控件。大写时的音高变化使用数字编辑框或微调框，便于精确调整。

NVDA 全局设置中的标点符号级别、自动方言切换、读出语言变化、Unicode 规范化、处理字符和符号时包含 Unicode 联盟提供的数据（包括表情符号）、其他符号发音词典、移动光标后读出字符解释和语音模式选项，仍保留在 NVDA 的语音设置中。

谷歌TTS会忽略 NVDA 自身针对本语音合成器发出的自动语言切换和自动方言切换命令，因此这些全局选项不会强制 谷歌TTS切换语音。需要本插件自动选择语音或配置文件时，请使用 谷歌TTS的自动语言配置文件。如果启用了 NVDA 的读出语言变化选项，则在自动语言配置文件开启时，所报告的语言名称会跟随 谷歌TTS的检测结果。关闭自动语言配置文件后，NVDA 仍可使用应用程序提供的语言切换信息来报告语言并处理字符和符号，包括标点符号发音词典，但 谷歌TTS不会根据这些命令切换语音。

自动语言配置文件会在 NVDA 处理文本之前设置语言上下文，因此 NVDA 的符号发音和语音字典处理仍会在所选语言上下文的常规语音流程中进行。

关闭自动语言配置文件时，NVDA 语音字典会照常应用于当前选中的 谷歌TTS变声。启用自动语言配置文件时，本插件会在 NVDA 处理相应文本段期间，临时使用各已启用语言配置文件所选变声的语音字典。NVDA 的默认字典和临时字典仍按其常规方式工作。

启用自动语言配置文件后，NVDA 的语音设置中不会为此语音合成器提供常规的语音、变声、速度、语速加倍、音调和音量控件，而会显示一条可获得焦点的提示，引导您前往 NVDA 谷歌TTS插件设置类别。停顿仍保留在语音设置中，并适用于 谷歌TTS的所有朗读内容。在此模式下，常规的循环切换合成器设置命令（例如台式机键盘上的 NVDA+Ctrl+方向键，或笔记本键盘上的 NVDA+Shift+Ctrl+方向键）会读出这条提示，而不会更改 谷歌TTS的语音或语音参数。启用自动语言配置文件时，谷歌TTS还会使用每个已启用配置文件中的大写字母和拼读选项；关闭该功能后，语音设置中的常规值会重新可用。NVDA 谷歌TTS插件设置类别中的状态信息也可通过 Tab 键获得焦点，以便屏幕阅读器读出。

解决 Edge 运行时无声问题

如果选择 Microsoft Edge 作为 Chromium 浏览器运行时，NVDA 谷歌TTS插件还会检查 Microsoft Edge WebView2 运行时是否可用。即使已经安装 Edge，WebView2 仍可能缺失或损坏，此时本插件无法通过 Edge 朗读。Google Chrome 和 Brave 不依赖 WebView2。

WebView2 是 Windows 原生应用程序用来承载网页内容的 Microsoft Edge 运行时。它与 Microsoft Edge 有关，但普通 Edge 浏览器可用并不一定意味着应用程序所需的 WebView2 运行时已经安装且状态正常。Microsoft 建议应用程序使用 Evergreen WebView2 运行时，因为它由多个应用共享并会自动更新；体积较小的 Evergreen Bootstrapper 会下载与设备架构匹配的运行时。

需要 WebView2 时，NVDA 谷歌TTS插件会提供以下按钮：下载 Microsoft 的在线 Evergreen Bootstrapper、打开 Microsoft WebView2 页面以获取离线安装程序或固定版本包，或者稍后再处理。在 WebView2 可用之前，NVDA 会继续使用先前的语音合成器。

如果 Windows 无法打开下载页面，本插件会在带有标签的只读编辑框中显示下载地址，并提供复制链接按钮，以便您将地址手动粘贴到浏览器中。

如果电脑可以联网，请从以下地址下载 Microsoft Edge WebView2 Evergreen Bootstrapper：下载 Microsoft Edge WebView2 运行时。

运行安装程序，重启 NVDA，然后重新选择 NVDA 谷歌TTS插件。如需离线安装程序或固定版本的 WebView2 运行时包，请打开 Microsoft WebView2 页面：Microsoft Edge WebView2。

注意事项

  • 使用 NVDA 时，无需让 Google Chrome、Microsoft Edge 或 Brave 浏览器窗口保持打开。本插件会自动在后台连接并处理语音。
  • NVDA 启动后首次朗读时，当前语音包的初始化可能需要片刻时间。

更新日志

1.1 版（2026-10-20）

  • 安全更新：增强与 Chromium 浏览器运行时内部通信的保护，拒绝来自外部网页源的连接。
  • NVDA 兼容性：更新对 NVDA 2027.1 的兼容支持。
  • 更新引擎：将随附的 WASM TTS 引擎更新至 2027xxxx.1 版。

1.0 版（2026-10-12）

  • 朗读启动更快、过程更顺畅：
    • 对于中长文本，本插件会先处理较短的首段，让语音更快开始，然后以较大的分段继续处理剩余文本。
    • 本插件可以复用暂存在 RAM 中的已生成音频。在开始播放前也会缓冲少量音频，以减少首次朗读长文本时出现的中断。
  • 更好地处理多语言文本：
    • 句子和短语分段现在使用范围更广的 Unicode 17.0 和 CLDR 48.2 官方标点及书写系统数据，从而改进对本地化标点、缩写、网址、表情符号、中日韩文字、泰语，以及其他通常不以空格分词的文本的处理。
    • 使用自动语言配置文件功能可以利用更广泛的书写系统覆盖，在文本较短或语言不明确时更准确地选择最可能的配置文件。
    • 无论音频是从 RAM 中复用还是重新生成，停顿设置和各分段之间的衔接都更加一致。
  • 音量更大、更稳定：
    • 本插件现在使用固定增益提高默认音量，防止朗读过程中音量异常地忽高忽低。音量设置仍按比例调节，并继续防止过高的峰值。
    • 部分男声的失真已经存在于原始 WASM TTS 引擎的输出中，因此本插件无法通过后期处理加以修复。这些更改旨在改善音量大小和稳定性，并非为了降低此类失真。
  • 提高可靠性：
    • 如果 Chromium 浏览器运行时或 WASM TTS 引擎在输出音频前发生故障，谷歌TTS会关闭发生故障的运行时，并使用新运行时重试一次。如果音频已经开始播放，本插件不会重试，以免重复朗读不完整的内容。
    • 让 谷歌TTS的浏览器运行时在后台保持就绪设置不再保留正忙、连接已断开或状态异常的运行时。
    • 本插件现在只加载自身随附的组件，从而减少与其他 NVDA 插件中同名组件发生冲突的情况。
    • 在受支持的 NVDA 版本中，如果 NVDA 音频输出设备发生变化或进入错误状态，本插件可以更可靠地恢复。
  • 更新组件和翻译：
    • 将随附的 WASM TTS 引擎更新至 20260917.1 版。
    • 新增西班牙语和巴西葡萄牙语的界面翻译及用户文档。
    • 重新翻译简体中文界面和用户文档，使表述更加自然，并与 NVDA 官方术语保持一致。

0.6 版（2026-07-30）

  • 更快地切换语音合成器：新增可选设置，使用户从其他语音合成器切换到 谷歌TTS时能够更快就绪。此设置默认关闭；开启后，NVDA 运行期间可能会占用更多内存。
  • 后台准备：启用此设置后，如果您更改所选 Chromium 浏览器运行时，或者安装或移除语音包，谷歌TTS会重新进行后台准备。
  • 提高切换可靠性：提高从 谷歌TTS切换到其他语音合成器时的可靠性，尤其是在朗读或语音准备任务尚未完全停止时。

0.5.5 版（2026-07-23）

  • 自动语言配置文件：改进 CLD2 与 谷歌TTS语言代码别名之间的自动语言配置文件匹配，包括菲律宾语/他加禄语、爪哇语、旧版希伯来语代码、挪威语变体、阿拉伯语，以及简体中文、繁体中文和粤语的映射。
  • CLD2 Windows DLL：改用 MSVC 而非 MinGW-w64 重新构建随附的 CLD2 Windows DLL，使打包后的插件不再触发此前 VirusTotal 检测中的误报。

0.5 版（2026-07-19）

  • 插件更新：在 NVDA 谷歌TTS插件设置类别中新增内置更新检查，包括可选的启动时检查、本地化更新信息、在 NVDA 内下载安装包、交由 NVDA 标准插件安装程序处理，以及支持同一公开版本号下的小型修补版本。
  • Chromium 运行时回退：改进 Chrome、Edge 和 Brave 之间的回退机制。如果所选浏览器运行时无法启动或尚未就绪，NVDA 谷歌TTS插件可以尝试其他受支持的运行时。如果 Edge 缺少 WebView2，而其他受支持的运行时可用，现在可以跳过 Edge。NVDA 谷歌TTS插件还会在浏览器仍在完成启动时等待并重试，从而减少少见的启动无声或浏览器连接失败。
  • NVDA 兼容性：改进新旧 NVDA 版本在语音、拼读、语音字典、设置、语音合成器切换、全局插件和语音合成器驱动等方面的兼容性。谷歌TTS还会阻止 NVDA 或应用程序的语言切换命令改变 Google 语音；关闭自动语言配置文件时，这些命令仍可用于报告语言以及处理字符和符号。
  • 简体中文、繁体中文和俄语本地化：新增简体中文、繁体中文和俄语界面翻译及用户文档。两个中文区域设置还包含本地化的插件元数据。
  • 语音可靠性：修复语音中断后偶尔重复播放不完整内容的问题，恢复 SeaNet 语音的音调控制，并避免切换到其他语音合成器后偶尔出现语音设置错误。新增可选的停顿缩短设置；可在 NVDA 语音设置（NVDA+Ctrl+V）中启用，详情请参阅“配置”一节。
  • 状态字段无障碍改进：使运行时、自动语言配置文件、更新、语音设置提示和手动网址回退等状态字段更容易获得焦点和查看，且不会延迟重复播报。

0.4 版（2026-07-16）

  • 自动语言配置文件：新增受 Android 上 Auto TTS 启发的 谷歌TTS分语言配置文件。可在 NVDA 谷歌TTS插件设置类别中进行配置；每种已启用的语言都可使用自己的变声、速度、语速加倍、音调、音量、大写字母处理和拼读方式；关闭此功能后，NVDA 的常规语音设置仍可使用。
  • NVDA 兼容性：改进对 NVDA 2024.1 至 2026 的兼容性，包括更安全地切换语音合成器和使用语音处理钩子；其他插件封装 NVDA 的语音合成器选择功能时也能更可靠地工作。
  • 多语言长文本朗读：改进包含非 ASCII 标点的文本，以及词间空格较少的书写系统中的句子和短语分段，并扩大基于 Unicode 的标点处理范围，以支持更多语言。
  • Chromium 运行时支持：新增 Brave 浏览器运行时支持，改进 NVDA 谷歌TTS插件设置类别中 Chrome、Edge 和 Brave 的回退行为，并明确说明只有使用 Microsoft Edge 时才需要 Microsoft Edge WebView2 运行时。

  • 设置无障碍改进：新增一个默认未分配的“按键与手势”命令，可直接打开 NVDA 谷歌TTS插件设置；改进状态字段，使屏幕阅读器能够更可靠地读出标签和完整信息；启用自动语言配置文件后，循环切换合成器设置命令会读出相关提示，而不是更改语音参数。这可以让配置文件管理的语音参数与 NVDA 的常规语音设置保持兼容。
  • 语音选择和可靠性：使语音与变声的选择更加清晰，更安全地预热语音包，改进语音管理器的语音包处理、中断朗读时的响应和语音包导入安全性，并修正英语（尼日利亚）等区域语言名称。
